# AttendX — Smart Attendance System

A mobile attendance system using QR codes for colleges.

## Download App
- [Download Latest APK](https://expo.dev/artifacts/eas/kyC2vkNhCZKrspxzmsos6f.apk)
- [Download Previous APK](https://expo.dev/artifacts/eas/rPEMXs6yhSpAXN1jJmx6yD.apk)

## How To Install
1. Download the APK link above on your Android phone
2. Tap the downloaded file
3. Allow "Install from unknown sources" if prompted
4. Install and open AttendX

## Login
Contact your admin for login credentials.
Your credentials will be emailed to you when your account is created.

## Tech Stack
- Frontend: React Native + Expo
- Backend: Node.js + Express
- Database: MongoDB Atlas
- Hosted on: Render (backend)
