# AttendX - Smart Attendance System

A mobile attendance system using QR codes for colleges and institutions.

## Download App
- https://expo.dev/artifacts/eas/kyC2vkNhCZKrspxmsos6f.apk
- https://expo.dev/artifacts/eas/rPEMXs6yhSpAXn1jJmx6yD.apk
- https://expo.dev/artifacts/eas/vuDwuVqQhC4Tu1yzUwcQfZ.aab

## How to Install
1. Download the APK link above on your Android phone
2. Tap the downloaded file
3. Allow "Install from unknown sources" if prompted
4. Install and open AttendX

##Login
Conatct your admin for login credentials.
Your credentials will be emailed to you when your account is created.

## Tech Stack
- Frontend: React Native + Expo
- Backend: Node.js + Express
- Database: MongoDB Atlas
- Hosted on: Render(backend)
